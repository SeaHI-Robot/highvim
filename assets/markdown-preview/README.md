# Markdown Preview themes

Each theme provides `markdown.css` for rendered content and `highlight.css`
for fenced code blocks. Select one with `markdown_preview_theme` at the top of
`lua/plugins/markdown.lua`.

Available themes:

- `catppuccin`: Catppuccin Latte and Frappe (default)
- `everforest`: Everforest Light and Dark
- `gruvbox-material`: Gruvbox Material Light and Dark
- `solarized`: Solarized Light and Dark
- `github`: the upstream markdown-preview.nvim theme

The preview follows the system light/dark preference by default. The built-in
light/dark switch remains visible in the preview header.
